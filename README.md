 # Explorador de Clima Aplicación que consulta el clima de cualquier ciudad usando la API de OpenWeatherMap. 
 ## Funcionalidades - Búsqueda por ciudad con validación de entrada 
 - Estados de carga y error con botón de reintentar 
 - Historial de las últimas 5 búsquedas 
 ## Cómo probarlo Abrir index.html con la extensión Live Server de VS Code.
